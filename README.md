## 손글씨 편지 작성 에이전트 구상

### 목표
사용자가 편지 내용을 입력하면 손글씨 스타일로 렌더링된 결과물을 만들어주는 에이전트를 구현합니다. 최종 출력물은 이미지(PNG/JPG) 또는 PDF로 제공하며, 사용자는 글씨체, 종이 배경, 여백, 줄 간격을 선택할 수 있도록 합니다.

### 핵심 사용자 흐름
1. 사용자가 편지 본문과 옵션(글씨체, 배경, 여백 등)을 입력한다.
2. 에이전트가 템플릿과 레이아웃 규칙에 따라 본문을 배치한다.
3. 손글씨 폰트/획 변형을 적용해 자연스러운 필기 질감을 만든다.
4. 결과물을 이미지/PDF로 내보내고 미리보기 링크를 제공한다.

### 기능 범위
- 입력: 편지 본문, 수신자/발신자 이름, 날짜, 문단 구분.
- 스타일: 폰트 선택, 종이 배경(흰 종이/노트/편지지), 여백/줄 간격.
- 출력: PNG/PDF 내보내기, 미리보기.
- 보정: 문단 자동 줄바꿈, 글자 간격 랜덤 변형(선택).

### 구현 아이디어
- 렌더링: HTML/CSS + 캔버스 또는 서버사이드 렌더링(Puppeteer/Playwright)로 이미지 생성.
- 폰트: 손글씨 폰트 여러 개를 프리셋으로 제공하고, 필요 시 커스텀 폰트 업로드 지원.
- 배경: 고해상도 종이 텍스처 이미지 템플릿을 선택적으로 합성.
- 레이아웃: A4/Letter 지원, 여백/줄 간격/문단 간격을 옵션화.

### 다음 단계

- 렌더링 프로토타입 제작 후 결과물 품질 검증.
- 사용자 피드백 반영해 옵션 확장.
